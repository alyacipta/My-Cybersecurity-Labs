## 🧠 My Learning Philosophy & Workflow

> [!TIP]
> ### 🔄 Solusi Praktis Agar Tidak Hilang Arah (The 80/20 Action Item)
> Biar tidak merasa *overwhelmed* [kewalahan] dan frustrasi karena merasa tidak hafal perintah terminal, saya menerapkan strategi **"Hacker Hemat Mood"**:
> 
> * **Document Every Step:** Setiap kali menyelesaikan satu level tantangan, saya langsung mendokumentasikannya ke dalam file `README.md` ini.
> * **Focus on Concepts, Not Syntax:** Cukup tulis kesimpulan inti dalam satu baris kalimat yang mudah dipahami.
>   * *Contoh Level 7:* Mencari kata spesifik di file teks ➔ Pakai `grep "kata" namafile`.
>   * *Contoh Level 8:* Menyaring baris yang hanya muncul sekali ➔ Pakai `sort namafile | uniq -u`.
> 
> Catatan di GitHub inilah yang menjadi **external brain** [otak kedua] saya. Dengan begitu, memori otak tidak perlu dibebani untuk menghafal hal-hal teknis yang kaku [rigid], melainkan fokus pada pengasahan *logical intuition*.
